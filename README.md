# Linux Distrochooser

Ein interaktiver, deutschsprachiger Linux-Distributionsberater. Beantworte acht Fragen (plus ggf. Zusatzfragen) und erhalte drei passende Vorschläge aus 22 Distributionsvarianten.

## Online ausprobieren

Nach Aktivierung von GitHub Pages: `https://<DEIN-GITHUB-NAME>.github.io/<REPOSITORY-NAME>/`

## Lokal starten

`index.html` im Browser öffnen. Keine Installation und kein Backend erforderlich. Für die Schriftarten und Distributionssymbole wird aktuell eine Internetverbindung benötigt.

## Bewertungsmodell

Die Empfehlungen beruhen auf einer redaktionell gepflegten, gewichteten Punktematrix. Sie sind Orientierungshilfen, keine objektiven Qualitätsurteile. Siehe [Konzept](docs/konzept.md), [Bewertungslogik](docs/bewertungslogik.md) und [Punktematrix](data/punktematrix.xlsx).

## Veröffentlichung

Repository auf GitHub anlegen, Dateien hochladen, dann **Settings → Pages → Deploy from a branch → main / (root)** wählen.

## Lizenz

Noch keine Lizenz vergeben. Der Quellcode ist öffentlich einsehbar, aber damit nicht automatisch zur Weiterverwendung lizenziert.
