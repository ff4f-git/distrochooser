Wo bekomme ich den Token?

Unter GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens einen Token mit kurzer Laufzeit anlegen. Nur das Repository „distrochooser“ auswählen und „Contents“ auf „Read and write“ setzen.
